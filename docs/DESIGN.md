# Native interface

T&S is a two-position switch for a pair of Macs. A TX/RX switch briefly confirms a keyboard-triggered mode change; connection and capture controls use familiar macOS forms.

- Base colours: window background #F5F5F5, primary ink #242424, secondary #6E6E73, iris #5752AD, confirmed green #197A63, attention orange #C46621. Native semantic colours adapt to dark mode; the menu-bar image is a system-tinted template.
- Typography: system San Francisco for controls, system rounded semibold for the small product title, compact bold TX/RX labels. No bundled fonts.
- Layout: a quiet header with the current mode, four native tabs, and a persistent Save/status footer. Connection leads with two explicit pairing steps. Network overrides and raw keys live under Advanced.
- The status-panel preview is labelled as a preview. Actual delivery panels do not activate or take focus.

The review removed duplicate send/receive credential forms. The same shared connection is visible regardless of mode; the mode switch applies immediately, while the footer saves edits. A global switch must not commit unfinished settings.
