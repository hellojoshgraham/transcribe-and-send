# T&S 0.4.1

The menu bar returns to its original T&S status icon and label, including recording, delivery and error indicators. After a successful mode-switch shortcut, the TX/RX switch appears for 0.5 seconds, then the normal indicator returns. A further successful shortcut restarts that half-second interval. Ignored or failed mode changes do not show a switch confirmation.

The mode control inside the menu and Settings remains visible. Pairing, shortcuts, recording, screenshots and automatic paste are unchanged. Replace the installed app after quitting it, using the same signing identity to preserve macOS privacy grants. No new pairing code is needed.
