# Scope and follow-ups

Supported: explicit voice recording, optional text auto-paste, local selected screenshots with manual paste, one paired connection used in either direction, and a configurable local TX/RX switch.

Outside scope: simultaneous TX and RX, switching the other Mac remotely, continuous clipboard monitoring, arbitrary files, image auto-paste, background capture, pre-login receiving, and an automatic updater.

Before a public binary release, complete the two-Mac acceptance checklist and Developer ID signing/notarization in RELEASING.md. Source distribution and a publicly installable signed binary are separate deliverables.
