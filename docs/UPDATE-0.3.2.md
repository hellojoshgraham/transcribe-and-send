# T&S 0.3.2 — historical release

Separated timeouts from cancellation, improved effective-permission diagnostics, and added stable-certificate build support.

For current installation, migration and acceptance steps, see [the current upgrade guide](UPDATE-0.4.0.md) and [README](../README.md). Earlier binary builds may use a different signing identity; keep one installed copy and renew only its required privacy permissions if macOS requests it.
